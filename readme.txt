Теоретическая часть:

1. Объясните, в чём заключается особенность технологии Grid.
   Укажите, что Grid позволяет создавать двухмерные сетки
   (работать с колонками и строками) и обеспечивает полное 
   управление размещением элементов.

Ответ:
    Grid — это технология CSS для создания двумерных сеток. 
    Её особенность заключается в возможности одновременно работать со строками и колонками, 
    обеспечивая полный контроль над размещением элементов внутри макета.
    Благодаря этому можно строить сложные макеты страниц и точно управлять расположением элементов внутри сетки. 

2. Перечислите основные отличия Grid от Flexbox. Поясните, что
   Flexbox подходит для одноосевого размещения элементов (по
   одной линии - строке или колонке), тогда как Grid удобен для
   создания сеток, где элементы располагаются как по строкам,
   так и по колонкам.

Ответ:
    Grid и Flexbox используются для создания макетов, но имеют разные особенности.

    Flexbox подходит для одноосевого размещения элементов, то есть по одной линии — либо по строке, либо по колонке. 
    Он удобен для выравнивания элементов внутри контейнера, создания навигации, меню и небольших блоков интерфейса.

    Grid предназначен для создания двумерных сеток, где элементы располагаются одновременно по строкам и колонкам. 
    Благодаря этому Grid удобен для построения сложных макетов страниц, галерей, 
    карточек товаров и других сеточных структур.

    Главное отличие заключается в том, что Flexbox работает с одной осью, а Grid — сразу с двумя осями.

3. Приведите примеры использования Grid, где его применение
   оправдано и незаменимо: создание сложных макетов страниц,
   например, карточек товаров в интернет-магазине,
   фотогалерей, табличных данных.

Ответ:
    Grid удобно использовать в случаях, когда требуется создать сложную сеточную структуру 
    и точно управлять расположением элементов по строкам и колонкам.

    Примеры применения Grid:
    - создание сложных макетов страниц с шапкой, боковой панелью, основным контентом и подвалом.
    - размещение карточек товаров в интернет-магазине.
    - создание фотогалерей.
    - отображение табличных данных.
    - построение адаптивных каталогов и портфолио.

    В таких задачах использование Grid особенно оправдано, 
    поскольку он позволяет удобно создавать и управлять двумерными сетками.

4. Объясните, как задаётся подключение Grid в CSS (например,
   с помощью свойства display: grid;) и приведите пример
   базовой разметки сетки.

Ответ:
    Для использования Grid необходимо задать контейнеру свойство display: grid;.
    После этого все дочерние элементы контейнера становятся элементами сетки и могут размещаться по строкам и колонкам.

    Пример базовой сетки:

.container {
    display: grid;

    grid-template-columns: repeat(3, 1fr);

    gap: 20px;
}

   В данном примере создаётся сетка из трёх колонок одинаковой ширины с расстоянием между элементами 20 пикселей.
